# 원본으로 홍보물

## 내 폰트와 집중 편집

- 이미지 더블클릭 또는 선택 후 **크게 열어 집중 편집**으로 포스터 한 장을 엽니다. 포스터 판 안의 이미지는 판 전체와 그 안의 글자·도형을 함께 엽니다. 판이 없으면 선택 이미지 영역을 사용합니다.
- **글자 추가** 후 내용을 입력하고 **내 폰트 넣기 · TTF / OTF**에서 파일을 고릅니다. 폰트는 이 브라우저의 IndexedDB에 저장되며 서버에 업로드하지 않습니다. 다른 PC에서 작업을 열면 같은 폰트 파일을 추가해야 합니다.
- 크기·색·자간·줄간격·정렬·외곽선·그림자를 수정하고 글자를 직접 드래그할 수 있습니다. 이미지에 이미 그려진 글자는 편집 가능한 글자 레이어가 아닙니다.
- **전체 캔버스로 돌아가기** 또는 닫기를 누르면 수정 내용이 반영됩니다. 편집 중 **되돌리기**, 레이어 숨김·잠금과 PNG 저장도 사용할 수 있습니다.
- `node scripts/test-poster-focus.cjs`는 개발 서버 3012에서 실제 TTF/OTF 파일 추가, 파일 선택창 열림, 글자 편집·드래그, 집중 편집 재진입, PNG 크기, 새로고침 후 폰트·편집 값 복원을 검사합니다.

왼쪽 작업 종류의 **원본으로 홍보물**에서 PNG·JPG·WebP 파일을 넣거나 선택한 캔버스 이미지를 가져옵니다. 제목·안내문을 입력하고 구도와 색감을 선택한 뒤 초안을 만듭니다.

- 원본 이미지의 데이터는 그대로 두고 전체가 보이도록 비례 축소해 배치합니다. 자동 자르기나 AI 재생성은 하지 않습니다.
- 제목과 상세 정보는 편집 가능한 글씨입니다. 이미지·글씨를 각각 이동하고 수정할 수 있습니다.
- 새 초안은 기존 작업 오른쪽에 추가합니다. 이전 이미지를 덮어쓰지 않습니다.
- 현재 크기는 1024×1536px 세로형입니다. 원본 보존 자동 배치 12종과 직접 작성한 색감 4종을 제공합니다. 제목·안내 영역에 맞춰 글자 크기와 줄바꿈을 조절합니다. 인쇄 원고의 해상도·교정은 별도로 확인하세요.
- 구도 명칭과 원칙은 [한국형 레이아웃 구성 도감](https://github.com/worlyung/korean-layout-compositions), CC BY 4.0을 참고하여 구현했습니다. 전체 278종이 자동 배치 템플릿으로 구현된 것은 아닙니다.
- 스타일 참고 자료에 사용자가 제안한 세 저장소를 연결했습니다. 외부 예시 이미지·프롬프트를 앱에 복제하거나 사용자의 API 공급자를 변경하지 않습니다. 링크 갤러리는 색감 버튼과 별개입니다.
- 이 초안 조합은 이미지 생성 API를 호출하지 않습니다. 원본 보존은 파일 데이터를 유지한다는 뜻이며, 화면·내보내기에서는 배치 크기에 맞춰 렌더링됩니다.

## 전체 구도 도감

이미지 만들기와 원본으로 홍보물의 **전체 구도 썸네일 보기**에서 278종을 검색·분류하고 설명을 읽을 수 있습니다. 한 페이지에 24종을 보여줍니다. **지금 적용 가능한 구도만**을 켜면 현재 모드에서 적용할 수 있는 항목만 보입니다.

- 이미지 생성: 포스터용 구도 24종을 생성 요청에 반영합니다. AI의 실제 결과가 지침을 정확히 따르는지는 별도 확인해야 합니다.
- 원본 보존: 위치·크기가 서로 다른 12종의 자동 배치를 적용합니다. 나머지 항목은 참고용으로 표시합니다.
- 전체 원문 목록과 썸네일은 앱에 포함합니다. 인터넷 없이 볼 수 있지만 원본 카드 외부 링크는 연결이 필요합니다.
- 출처·고정 버전은 `public/layout-catalog/SOURCE.json`, 이용 조건은 같은 폴더의 `LICENSE.txt`에 기록합니다. 갱신 스크립트는 `scripts/sync-layout-catalog.py`입니다.
- `node scripts/test-layout-gallery.cjs`는 개발 서버 3012에서 전체 썸네일 디코딩, 검색·필터, 구도 적용 및 12종 초안의 원본 데이터 보존을 확인합니다.

검증: TypeScript·ESLint, 터담의 `tests/test_event_render_live.cjs` (`RENDER_ROUNDTRIP=1`)에서 업로드→초안 작성→저장된 원본 데이터 동일성 및 독립 텍스트 레이어를 확인합니다.
