# 제공자별 되는 것 / 안 되는 것

곰곰 캔버스는 세 제공자를 쓸 수 있다. **되는 기능이 서로 달라서** 화면에서도 제공자를 바꾸면 못 쓰는 버튼이 잠긴다.

> ✅ = 우리가 실제 호출해 확인함 · ⚠️ = 문서 기준(미검증) · ✗ = 지원 안 함
> 확인 일자: 2026-08-20

## 한눈에 보기

| 기능 | OpenAI `gpt-image-2` | Gemini 나노바나나 (`gemini-3-pro-image` / `3.1-flash-image`) | xAI `grok-imagine-image-2.0` |
|---|---|---|---|
| 이미지 생성 | ✅ | ✅ | ✅ |
| 참조 이미지로 생성 | ✅ (최대 16장) | ✅ (최대 3장) | ✅ (**1장만**) |
| 부분 수정 (마스크 인페인팅) | ✅ | ✗ | ✗ |
| 글자 수정 | ✅ | ✗ | ✗ |
| 사이즈 전개 (아웃페인팅) | ✅ | ✗ | ✗ |
| 투명 배경 | ✅ | ✗ | ✗ |
| 크기 지정 | ✅ 픽셀 단위 | ⚠️ 비율만 (1:1·4:3·16:9…) | ✗ 고정 |
| 품질 단계 | ✅ 고·중·저 | ✗ | ✅ 중·저만 |
| 화면 속 한글 | ✅ 정확한 편 | ✅ 좋음 | ⚠️ 짧은 글자만 확인 |

## 제공자별 메모

### OpenAI gpt-image-2 — 기본값, 모든 기능 지원
캔버스의 핵심 기능(부분수정·글자수정·투명배경·사이즈 전개)이 전부 이 모델의 마스크·배경 기능에 기대고 있다. **다른 제공자로 바꾸면 이 기능들은 잠긴다.**

크기 규칙(실측):
- 가로·세로 모두 **16의 배수**
- 가장 긴 변 **3840px 이하**
- 전체 **약 440만 픽셀 이하** (1760×2480 통과 / 2480×3504 거부)
- 따라서 **A4 210dpi(1760×2480) 직접 생성 가능** — 인쇄물에 바로 쓸 수 있다

### Google Gemini (나노바나나) — 시안 대량 생산에 좋다
캔버스에서 모델을 고를 수 있다(실측 확인):

| 고르는 값 | 모델 | 쓸 곳 |
|---|---|---|
| 나노바나나 프로 (품질) | `gemini-3-pro-image` | 품질이 필요할 때 |
| **나노바나나 2 (빠름)** | `gemini-3.1-flash-image` | 시안 대량 생산 |
| 나노바나나 2 라이트 | `gemini-3.1-flash-lite-image` | 더 싸고 빠르게 |
| 2.5 플래시 (구형) | `gemini-2.5-flash-image` | 예전 결과 재현용 |

생성과 참조는 잘 되고 한글도 준수하다. 다만 **픽셀 크기를 못 받고 비율만** 받는다. 캔버스는 고른 크기에서 가장 가까운 비율로 자동 변환해 보낸다(예: 1024×1536 → `2:3` → 실제 848×1264).

부분수정·투명배경이 없어서 **"뽑아보는" 단계에 어울리고, 다듬기는 OpenAI로 넘기는** 편이 낫다.

### xAI Grok — 크레딧을 따로 사야 쓴다
모델은 `grok-imagine-image-2.0`. 생성과 참조 편집(최대 3장)은 문서상 지원하지만 **마스크·투명배경·크기 지정은 없다.** 품질은 `low`/`medium`만(캔버스에서 "고품질"을 골라도 medium으로 보낸다). 공시 단가는 이미지당 약 $0.04.

🔴 **가장 헷갈리는 함정 — 그록 구독과 API는 별개다.**
grok.com이나 X Premium 구독을 쓰고 있어도 **API 크레딧은 한 푼도 딸려오지 않는다.** [console.x.ai](https://console.x.ai)에서 결제수단 등록 + 크레딧 충전을 따로 해야 한다.
크레딧이 없으면 `/v1/models` 같은 **조회 API까지 전부 403**이다 — 403 `permission-denied`가 뜨면 키 문제가 아니라 크레딧 문제다.

사용 가능한 모델(실측): `grok-imagine-image`, `grok-imagine-image-2.0`, `grok-imagine-image-quality` — 셋 다 text·image 입력을 받는다.

⚠️ **참조 편집 요청 형식이 OpenAI와 다르다**(실측으로 알아낸 부분):
- multipart가 아니라 **JSON** (`Content-Type: application/json`)
- `image`는 배열이 아니라 **객체**이고 `image_url`은 **문자열 하나** → **참조는 1장만** 넣을 수 있다

## 어떻게 고르나

| 상황 | 추천 |
|---|---|
| 제안서·포스터 최종본, 인쇄물 | **OpenAI** (크기·품질·수정 전부 필요) |
| 이미 만든 걸 고치기 | **OpenAI** (다른 제공자는 수정 기능 없음) |
| 아이디어 시안 여러 장 빠르게 | **Gemini 나노바나나 2** (빠르고 싸다) |
| 그록 그림체가 필요할 때 | **Grok** — 크레딧 충전 필요, 참조는 1장 |

## 키 넣는 법

설정(⚙️) → 제공자별 키 입력. 키는 **서버에만** 저장되고(`.env.local`) 브라우저로는 내려오지 않는다. 이미 `~/.env`나 환경변수에 키가 있으면 자동으로 인식한다.

여러 사람이 쓰는 서버라면 `LOCK_KEY_EDITING=1`로 키 편집 화면을 잠글 것.
