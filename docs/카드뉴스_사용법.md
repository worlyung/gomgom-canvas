# 카드뉴스 스튜디오

곰곰 캔버스 상단의 **카드뉴스 만들기**를 누르면 열려요.

1. 왼쪽에서 카드를 선택하고 오른쪽에서 표지·사진과 이야기·번호 목록·안내 사항·정보 박스·마무리·브랜드 카드 중 하나를 골라요.
2. **내 사진으로 배경 바꾸기**로 JPG·PNG·WebP를 넣거나, 캔버스에 있는 사진을 선택해요. 사진은 한 장에 20MB까지 열 수 있고 편집용으로 긴 변 2160px 이내로 조정돼요.
3. **정렬 · 간격 맞춤**에서 브랜드·제목·본문을 선택하고, **글씨**에서 문구, 색상, 크기, 굵기, 위치를 바꿔요. 미리보기의 글씨를 눌러 선택하거나 끌었다 놓아 이동할 수도 있어요.
4. 배경 사진의 확대·좌우·상하 위치와 어둡기를 조절해요. 배경을 교체해도 글씨는 유지돼요.
5. 왼쪽에서 카드를 추가·복제·삭제하고 순서를 바꿔요. 한 작업에 최대 20장이에요.
6. **전체 PNG 저장**으로 1080×1350 이미지가 01.png부터 순서대로 담긴 ZIP을 받아요. 글씨가 안전 영역을 벗어나면 먼저 위치나 크기를 수정해요.

## 정렬과 간격 맞추기

**글씨 → 글꼴**에서 이 PC에 설치된 글꼴을 선택해요. 이름으로 검색할 수 있고, 제목과 본문마다 따로 지정할 수 있어요. 미리보기·PNG·캔버스 사본에 적용되며 작업 파일에도 선택한 글꼴 이름이 저장돼요. 글꼴 파일 자체는 포함되지 않으므로, 다른 PC에 같은 글꼴이 없으면 안내와 함께 맑은 고딕으로 대신 표시·저장돼요. 예전 작업 파일은 맑은 고딕으로 열려요.

- 미리보기 글상자나 오른쪽 브랜드·제목·본문 버튼을 **Shift+클릭**하면 여러 개를 선택해요. 다시 Shift+클릭하면 그 글상자만 선택에서 빠져요.
- 2개 이상 선택하고 **왼쪽 / 가로 가운데 / 오른쪽 / 위쪽 / 세로 가운데 / 아래쪽 맞춤**을 눌러요. 선택한 글상자 전체의 바깥 범위가 기준이에요.
- **가로 간격 동일하게 / 세로 간격 동일하게**는 3개 이상 선택했을 때 사용해요. 양 끝 글상자는 그대로 두고 글상자 사이의 빈 간격을 같게 만들어요. 공간이 부족하면 양 끝 글상자를 먼저 벌려 주세요.
- **카드 가로 중앙 / 카드 세로 중앙**은 선택한 글상자들을 한 묶음으로 카드 중앙에 옮겨요. 하나만 선택해도 사용할 수 있어요.
- **문단 정렬**은 글상자 안의 글씨를 왼쪽·가운데·오른쪽으로 맞춰요. 여러 글상자를 선택했다면 모두 적용돼요. 문구·색상·크기 입력은 마지막으로 선택한 글상자를 바꿔요.
- 여러 글상자를 선택한 뒤 하나를 끌면 함께 움직여요. 드래그 중 다른 글상자나 카드의 끝선·중심선에 가까워지면 분홍 안내선이 나타나며 붙어요. **Alt**를 누르거나 **안내선과 자동 맞춤** 체크를 끄면 자유롭게 움직여요.
- 안내선은 편집할 때만 보이며 PNG나 캔버스 사본에는 들어가지 않아요. 정렬과 그룹 이동은 **되돌리기** 한 번으로 복원돼요.

## 계속 수정하거나 직원에게 전달하기

- **작업 파일 저장**은 사진과 편집 가능한 글씨를 함께 `.cardnews.json`으로 저장해요.
- **작업 열기**로 이 파일을 열면 계속 수정할 수 있어요. 현재 작업을 교체하기 전에 필요하면 작업 파일을 저장해 주세요.
- 최근 작업은 해당 PC의 브라우저 저장소에도 자동 저장돼요. 다른 PC와 자동 동기화되지는 않으므로 전달할 때는 작업 파일을 사용해요.
- **전체 카드를 캔버스에 추가**는 사진·글씨·도형을 나눈 편집 가능한 사본을 기존 캔버스 오른쪽에 추가해요. 스튜디오 원본과 캔버스 사본은 서로 자동으로 반영되지 않아요. PNG 묶음 출력은 스튜디오의 작업을 기준으로 해요.

## AI 배경

**AI로 배경 만들기**를 펼쳐 원하는 장면을 적고 **이 카드 배경 1장 생성**을 눌러요. 기존 곰곰 캔버스 OpenAI 연결을 사용하며 API 비용이 발생해요. 사진 업로드, 글씨 편집, 파일 저장은 AI 호출 없이 작동해요.
